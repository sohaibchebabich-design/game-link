# كيف تنشر الموقع وتحدّث الرابط

## النشر (مرة واحدة فقط)

1. اذهب إلى https://github.com وسوّي حساب (لو ما عندك)
2. اضغط "New repository" وسمّه مثلاً: game-link
3. ارفع فيه ملفين: index.html و data.json (اسحبهم وأفلتهم في صفحة الرفع)
4. روح لإعدادات الريبو (Settings) → قسم Pages
5. تحت "Source" اختر "main" واضغط Save
6. بعد دقيقة، رابطك جاهز على شكل:
   https://اسم-حسابك.github.io/game-link/

هذا الرابط ثابت ولا يتغير أبداً. أرسله لصديقك مرة واحدة وخلاص.

## تحديث الرابط كل مباراة

1. روح لملف data.json داخل الريبو على GitHub
2. اضغط على أيقونة القلم (Edit)
3. غيّر القيمة اللي جنب "url" لرابط المباراة الجديد، مثلاً:
   { "url": "https://example.com/room/123", "updatedAt": "" }
4. اضغط Commit changes

صديقك بس يدخل على نفس الرابط الثابت، يكتب اسمه، ويضغط "تحديث الرابط" ليشوف آخر رابط حطيته.
